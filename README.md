# React-Food-Delivery-App

## 🍔 Tasty Burger – Food Ordering Web Application
Tasty Burger is a modern, high-performance food ordering web application built using React 18, React Router, and Bootstrap.
It provides a visually rich, smooth, and intuitive platform for users to explore food items, view promotions, and place online orders.
The project is designed to simulate a real-world restaurant website, focusing on UI/UX, component reusability, responsive design, and scalable architecture.

## 🧠 Application Overview

The application provides a seamless experience similar to popular food delivery platforms. It includes:
* **A promotional landing page**
* **A full navigation bar with multiple pages**
* **A product-focused shopping experience**
* **A visually attractive hero section with featured burgers and pricing**
* **The design emphasizes user engagement, accessibility, and commercial-style UI layout.**

##✨ Key Features

* **The Tasty Burger application focuses on both functionality and aesthetics, including:**
* **Modern Landing Page – Displays featured burgers, pricing, and promotional offers.**
* **Multi-Page Navigation – Seamless routing between Home, About, Menu, Shop, Blog, and Contact using React Router.**
* **Shopping Cart UI – Cart icon with live item count, designed for checkout system expansion.**
* **Product Display – Food cards with images, names, and prices.**
* **Responsive Design – Optimized for desktop, tablet, and mobile screens.**
* **Fast Performance – Powered by React 18 and optimized build process.**

##🔧 Technologies Used

* **Frontend Framework: React 18**
* **Routing: React Router DOM**
* **UI Framework: Bootstrap, React-Bootstrap, Bootstrap Icons***
* **Styling: CSS3***
* **Build Tool: Create React App***
* **Testing: React Testing Library***
* **Version Control: Git & GitHub***
